  2. 貼上以下 3 行程式碼並儲存：
    function doPost(e){ var s=SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var d=JSON.parse(e.postData.contents); s.appendRow([d.code,d.category,d.name,d.sub,d.desc,d.day,d.mapQuery,d.lat,d.lng]); return ContentService.createTextOutput("OK"); }
  3. 點擊右上角 部署 ➔ 新增部署 ➔ 種類選擇「Web 應用程式」。
  4. 誰有權存取選擇：「所有人 (Anyone)」，部署後複製網址貼至上方框中即可！
